# AudioGo

Windows 桌面修音工具，提供音訊載入、波形／頻譜檢視、播放、區段編輯（剪下／貼上／
裁切／淡化），以及取樣類型轉換、高通濾波、降噪、圖形化等化器與響度處理。

## 系統需求

- Windows 7 / 8 / 10 / 11（64-bit）
- 無需安裝，解壓縮後直接執行 `audiogo.exe`

## 使用方式

1. 下載並解壓縮 `AudioGo-win64-v<版本>.zip`
2. 執行資料夾內的 `audiogo.exe`
3. 拖放音訊檔案（WAV、MP3、FLAC）至視窗，或使用選單「檔案 → 開啟」。
   **僅支援單聲道與立體聲**，超過 2 聲道的檔案會被拒絕開啟
4. 從「處理」選單套用處理，或使用快捷鍵。

   | 按鍵 | 功能 |
   |------|------|
   | F11 | 轉換取樣類型 |
   | H | 高通濾波，每按一次進到下一段 cutoff（20 / 50 / 100 / 200 / 300 / 400 / 600 / 800 / 1000 Hz，到頂即停，不繞回） |
   | N | 自動降噪 1 dB（Ctrl 加按為 3 dB），全檔 |
   | Alt+N | 從選取範圍擷取噪音樣本（需框選一段純噪音，最短約 0.24～0.32 秒，依取樣率而定） |
   | Shift+N | 樣本降噪 1 級（Ctrl 加按為 3 級）；有選取時只作用於該範圍 |
   | Ctrl+G | 開／收圖形化等化器（會自動切到頻譜檢視） |
   | `/` | 小聲補強 1 dB（Ctrl 加按為 3 dB） |
   | `+` / `−` | 音量增加／減少 1 dB（Ctrl 加按為 3 dB） |
   | Ctrl+M | 自動響度最大化（一鍵推至交付響度） |
   | Ctrl+I | 反相 |
   | Ctrl+R | 倒放 |
   | Shift+F | 波形／頻譜檢視切換 |
   | B | 原始／處理結果比較切換 |
   | Ctrl+Z | 復原 |

5. 在波形上拖曳可框選區段；處理操作若支援片段處理則只作用於該範圍，否則作用於
   整個檔案（**自動降噪與高通濾波為全檔操作，不受選取範圍影響；樣本降噪則會只作用於
   選取範圍**）。
   波形上**雙擊**或按 **Ctrl+A** 可全選整個檔案；`Shift+←／→` 可用鍵盤延伸選取，
   `Shift+Home／End` 延伸至檔頭／檔尾
6. 選取範圍可用「編輯」選單的指令修改，或使用快捷鍵。

   | 按鍵 | 功能 |
   |------|------|
   | Ctrl+X / Ctrl+C / Ctrl+V | 剪下／複製／貼上 |
   | Delete | 刪除選取範圍 |
   | Ctrl+T | 裁切為選取範圍（只留下選取的部分） |
   | Ctrl+L | 選取範圍靜音 |
   | Ctrl+Shift+L | 於編輯游標插入靜音 |
   | Ctrl+Shift+I / Ctrl+Shift+O | 淡入／淡出 |

7. 滿意後用 Ctrl+S 儲存，或 Ctrl+Shift+S 另存為 WAV。
   **存檔格式跟隨來源檔**——沒有主動用「轉換取樣類型」改過，就存回原本的型態

降噪、音量與小聲補強皆為「按一次加一級」，連按可累加，`Ctrl+Z` 退回上一級。
高通濾波同樣按一次進一段，**取消高通亦用 `Ctrl+Z`**。

**等化器**（v0.2.4-dev.2 起）：`Ctrl+G` 開啟後在右側曲線上點空白處新增控制點、拖曳
調整增益與頻率、滾輪調整 Q 值，或從上方選單套用人聲預設集。EQ 疊在所有處理之上且
**不會累積疊加**——反覆調整曲線聽到的永遠就是曲線當下的樣子。播放中也可以直接調，
聲音不會中斷。

完整快捷鍵與功能說明見
[原始碼 repo 的 README](https://github.com/LinChihShan/AudioGo#readme)。

## 檔案完整性

每個版本皆附 `.sha256` 檔案，可用 PowerShell 核對：

```powershell
Get-FileHash -Path AudioGo-win64-v0.2.4-dev.2.zip -Algorithm SHA256
```

ZIP 內另含 `BUILD-METADATA.txt`，記錄版本、來源 commit 與建置時間。
